# INQ EDU Website

A standalone INQ EDU brand website hosted inside the existing `studytool` GitHub Pages repository.

## Preview

Once GitHub Pages publishes the latest commit, open:
https://aplusachiever3.github.io/studytool/inq-edu/

## Structure

- `index.html` — single-page brand website with Home, About, Programmes, Tutors, Results, Insights and Contact sections.
- `assets/css/style.css` — responsive navy-and-gold brand system and layouts.
- `assets/js/main.js` — mobile navigation and consultation enquiry interaction.

## Deployment

The parent repository's existing GitHub Pages deployment from `main` / root serves this folder at the preview URL above. The original P1–P6 English learning website at the repository root is kept separate and unchanged.

## Before launch

- Replace the consultation form's empty `mailto:` recipient with the confirmed INQ EDU enquiry email address.
- Replace or approve the stock photography and confirm image licensing for commercial use.
- Review the copy, programme descriptions, contact details and tutor/results content before publishing as official information.

This website is a front-end static site. The consultation form prepares an email in the visitor's mail application; it does not send or store submissions on a server.
